# Lyrics Finder Web Project

This project is a simple web application that allows users to search for song lyrics by entering the artist name and song title. It uses the Lyrics.ovh API to fetch the lyrics.

## Technologies Used:
- **HTML**: Structure and content of the webpage.
- **CSS**: Styling of the webpage.
- **Thymeleaf**: For dynamic content rendering.
- **Java (Spring Boot)**: Backend for handling requests and fetching lyrics using the Lyrics.ovh API.

## Features:
- Accepts artist name and song title from the user.
- Fetches the lyrics using the Lyrics.ovh API.
- Displays the lyrics on the webpage.
- Simple and clean design with blue gradient background and responsive layout.
